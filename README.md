# بيانات المعلمين — مدارس نخبة الشمال الأهلية

صفحة عربية مخصصة للجوال تجمع البيانات في Supabase. لوحة الإدارة في `/admin` وتصدر ملف XLSX حقيقيًا بنفس الأعمدة الستة عشر وتسمياتها وترتيبها في الملف المرفق. الملف الأصلي على جهازك لا يتغير تلقائيًا؛ الصادرات تحتوي البيانات المحفوظة وقت التنزيل. يتولد التصدير داخل متصفح المدير دون إرسال البيانات لطرف آخر.

## التفعيل مرة واحدة

1. افتح SQL Editor للمشروع `nsdcxjuyylsjdouljpie` وشغّل محتوى `supabase/setup.sql`.
2. من Authentication → Users → Add user → Create new user أنشئ حساب مدير بالبريد الذي تملكه وكلمة مرور قوية، وفعّل Auto Confirm. البريد المجهز في SQL هو `moahmed7412@gmail.com` (حساب GitHub المتصل). غيّره في آخر أوامر SQL إذا أردت بريدًا مختلفًا.
3. أعد تشغيل أمر `insert into public.teacher_form_admins ...` الموجود أسفل SQL بعد إنشاء المستخدم، ثم تحقق أن الاستعلام الأخير يعيد حساب المدير.
4. افتح `/admin` وسجّل الدخول بالبريد وكلمة المرور التي اخترتها.

لم يُشغّل SQL آليًا لأن الحسابات المتصلة لا تملك صلاحية هذا المشروع. المفتاح العام المقدم لا يسمح بإنشاء الجداول أو مستخدمي الإدارة. لا يطلب التطبيق مفتاح service_role ولا يخزّنه.

## السلوك والخصوصية

- لا يلزم المعلم تسجيل دخول. الدرجات اختيارية عند عدم أداء الاختبار، وصفر درجة صحيحة.
- قوائم المرحلة والجنس والرتبة تطابق بيانات الملف. صحّحنا تهجئة جازان في قائمة الإدارات.
- التحقق من البيانات في الواجهة وقيود Postgres. تطبيع الأرقام العربية والفارسية. الهوية 10 أرقام ومنع تسجيل هوية مكررة. التصحيح عبر إدارة المدرسة في Supabase حاليًا.
- صلاحيات الجمهور: إضافة فقط، دون قراءة أو تعديل أو حذف. لا يستطيع المعلم قراءة بيانات المعلمين.
- صلاحيات المدير: القراءة عند وجود UID الخاص به في جدول `teacher_form_admins` فقط. لا تمنح عضوية الإدارة بناءً على بيانات metadata يكتبها المستخدم.
- جلسة المدير وبيانات النموذج في الذاكرة فقط، ولا تُخزن في localStorage. تحديث الصفحة يتطلب إعادة تسجيل الدخول.
- لا توجد تحليلات أو تتبع أو اعتماديات خارجية أو خطوط خارجية. لا يحتوي المستودع بيانات معلمين حقيقية.
- نقطة الإضافة مجهولة الهوية، مناسبة لتوزيع رابط داخلي محدود. حقل honeypot يقلل الروبوتات البسيطة لكنه ليس بديلًا لتحديد المعدل أو CAPTCHA إذا انتشر الرابط للعامة.
- لوحة الإدارة تجلب الصفحات حتى نهاية الردود؛ التصدير يشمل جميع الردود بصرف النظر عن مرشحات العرض.

## التشغيل والتحقق

لا تحتاج اعتماديات npm أو خطوة build. Vercel يستضيف الملفات مباشرة من الجذر، مع rewrite لمسار الإدارة وترويسات الأمان.

```sh
npm test
npm run dev
```

قبل استخدام بيانات حقيقية، جرّب إرسال سجل اختباري، وتأكد أن القراءة بمفتاح anon مرفوضة، وأن المدير المعتمد وحده يرى السجل، وأن XLSX يحافظ على أصفار الجوال والهوية. لا تُسجَّل نتائج هذه الاختبارات كناجحة قبل تفعيل SQL.

## تحديث المرحلة والرخصة المهنية

خيار المرحلة أصبح عالمي بدل رياض أطفال. شغّل `supabase/global-stage.sql` على قاعدة قائمة لقبول عالمي مع الإبقاء على السجلات التاريخية. رتبة المعلم اختيارية؛ عدم اختيار رتبة يُحفظ بالقيمة المتوافقة «لا يوجد». زر الحصول على الرخصة يتحكم بإظهار درجتي الاختبار فقط، وإلغاء تفعيله يمسح الدرجات المخفية؛ لا يضيف عمودًا إلى تصدير Excel.
